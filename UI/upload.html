Below are the feature supported by us:
  1. User Data Upload: user can upload h5 file which has stacked large numpy arrays and information about file. Currently we are intaking ECHO1 sagittal plane knee images from QDESS GE Scanners.User will get uuid upon upload which can be used for historical reference and preventing reuploading of same image to the cloud. Data will be persisted for 30 days and deletion can only be done by MRAI team members. No PHI data must be uploaded to website. H5 images are anonymized and numpy arrays from DICOM (Digital Imaging and Communications in Medicine) image.
  2. Tissue Segmentation : Only 7 tissues will be part of segmentation which are Meniscus,ACL, PCL, Femoral Cartilage, Patellar Cartilage and Tibial Cartilage. Model has not been trained for any other tissue which can be found in knee.
  3. Pathology Detection : Only 4 pathological categories model can detect such as Meniscal Tear, Ligament Tear, Cartilage Lesion and Effusion.Model has not been trained for any other pathological category which can be found in knee.

Instructions for a successful upload

  1. File must be a .h5 file
  2. Dataset name within h5 file must be "echo1"
  3. At the moment, our product only supports knee MRI images. Support for other MRI scans are currently in development
  4. If you are running into any issues uploading files, this may be due to your browser settings. Please try doing the following:
    • Hard refresh of the page
    • Clear browser cookies and history
    • Try another browser
