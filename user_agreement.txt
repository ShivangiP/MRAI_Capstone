Below are the feature supported by us:
a) User Data Upload: user can upload h5 file which has stacked large numpy arrays and information about file. Currently we are intaking ECHO1 sagittal plane knee images from QDESS GE Scanners.User will get uuid upon upload which can be used for historical reference and preventing reuploading of same image to the cloud. Data will be persisted for 30 days and deletion can only be done by MRAI team members. No PHI data must be uploaded to website. H5 images are anonymized and numpy arrays from DICOM (Digital Imaging and Communications in Medicine) image.

b) Tissue Segmentation : Only 7 tissues will be part of segmentation which are Meniscus,ACL, PCL, Femoral Cartilage, Patellar Cartilage and Tibial Cartilage. Model has not been trained for any other tissue which can be found in knee.

c) Pathology Detection : Model can detect only abnormality with respect to 4 pathological categories  such as Meniscal Tear, Ligament Tear, Cartilage Lesion and Effusion.Model has not been trained for any other pathological category which can be found in knee.
